# Diamond Radio ATS-25 USB PC Control 1.0.0

First public release of the standalone offline Windows PC Control application.

## Included

- Complete ATS-25 USB receiver console.
- FM/HF tuning, modes, bandwidth, step, AGC, ATT, volume, mute, seek, and BFO.
- Live spectrum/waterfall and radio-side 3D waterfall control.
- FT8/FT4/FT2 presets and decodes, plus CW and RTTY text views.
- Favorite stations and the bundled EiBi schedule.
- Offline FT8 world map, country data, country flags, and map styles.
- Chrome or Edge app-mode launcher with a clickable local address.
- Direct links to the Diamond Radio website and companion offline-tool projects.
- Simplified navigation showing only the bundled PC Control and FT8 Map pages.

No Python installation, account, website, or internet connection is required for USB control and local features. POTA and SOTA live spots require internet.

## Download and use

The **Windows ZIP** is recommended and includes the EXE, read-me, and legal notices. The **standalone EXE** contains the complete application and all local assets.

Connect the radio by USB, run the application, click **CONNECT** in the console, and select its COM port. Keep the launcher open during use. Only one program or browser page can hold the COM port at a time.

This build was tested by the project owner with an ATS-25. The package also passed asset, encryption, JavaScript, HTTP-security, GUI, browser-rendering, and ZIP-integrity checks.

This repository contains binary releases and notices only; Diamond-specific source code is not distributed.
